# 0.1.x stabilization (non-breaking)

This band focuses on **documentation, examples, CLI DX, and doctor** — no intentional public API breaks.

## What changed in docs/tooling

- Canonical onboarding: [docs/getting-started.md](../getting-started.md)
- Production guide: [docs/production-checklist.md](../production-checklist.md)
- Example apps under `examples/`
- `webspresso doctor` extended checks (secrets, lockfile, plugins, optional migrations)
- CLI `--template` presets: `blog`, `admin`, `dashboard`, `landing` (additive)

## Upgrade steps

```bash
npm update webspresso
npx webspresso doctor --db --strict
```

If you use the email plugin, ensure build includes `emails/*.mjml` or bundled templates (see README email section).
