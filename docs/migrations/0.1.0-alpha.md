# Upgrading to 0.1.0-alpha

Summary of the alpha release. Full list: [CHANGELOG.md](../../CHANGELOG.md).

## Breaking / major changes

- **HTTP stack:** Express replaced by **Hono** with compat layer — existing `(req, res, next)` handlers continue to work.
- **Build pipeline:** `webspresso build` produces `.webspresso/` manifest and bundles per adapter.

## New capabilities

- Cloudflare Workers adapter with precompiled Nunjucks templates
- `webspresso add deploy --provider cloudflare`
- Email plugin (MJML + Nodemailer, Node-oriented; manifest templates on Workers)
- Auth token flows (`authTokens`, password reset, email verify) when paired with email plugin

## Upgrade steps

```bash
npm install webspresso@0.1.0-alpha.0
npx webspresso doctor
```

Review `server.js` and `config/app.js` for deprecated Express-only APIs (grep your project for `deprecated`).
